### [C.U.T.Y. — Desktop Companion Robot](https://github.com/santi-bnt/C.U.T.Y)

**C.U.T.Y. — Cute Utility That Yaps** is an expressive desktop companion robot built around a Raspberry Pi 5 and STM32F401 architecture.

The current system integrates conversational AI, real-time voice interaction, animated facial expressions, camera-based face tracking, computer vision, touchscreen interaction, and custom electronics. A two-layer carrier PCB was designed in KiCad to integrate the Raspberry Pi, STM32, power distribution, UART communication, and peripheral connections.

**Technologies:** `Python` `Raspberry Pi 5` `STM32F401` `Computer Vision` `Gemini Live` `UART` `KiCad`

---

### [SkiliAir — Air Quality Monitoring System](https://github.com/santi-bnt/raspberrypi-air-quality-monitor)

Raspberry Pi based air-quality monitoring system that measures PM2.5 and PM10 sensor data and exposes live measurements through a Flask REST API.

The system includes MySQL logging, live visualization, LCD output, and threshold-based control of LEDs, a buzzer, and ventilation hardware.

**Technologies:** `Python` `Flask` `MySQL` `Raspberry Pi` `Linux` `REST APIs`

---

### DC Motor PID Position Control System with WebXR Interface

Real-time motor position-control system built around an ESP32 and FreeRTOS.

The controller uses incremental encoder feedback, a 10 ms control loop, PID control, and PWM actuation through a BTS7960 motor driver. A web and VR interface communicates with the embedded system through REST, MQTT, and WebSockets for remote setpoint control and real-time telemetry.

**Technologies:** `C++` `ESP32` `FreeRTOS` `PID` `MQTT` `WebSockets` `REST`
